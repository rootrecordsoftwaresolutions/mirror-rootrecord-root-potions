# Commands and permissions

## Commands

| Command | Description | Permission | Usage |
|---------|-------------|------------|-------|
| `/potions` | Search how to brew potions | `` | `/<command> [list/search/reload] [query/page]` |

## Permissions

| Permission | Description | Default |
|------------|-------------|---------|
| `rootpotions.use` | Use /potions | `true` |
| `rootpotions.reload` | Reload root-potions.yml | `op` |
